# ---------------------------------------------------------------------
# MeloTTS-ZH runtime dependencies (Windows ARM64 and x86/AMD64).
#
# IMPORTANT: install this file with --no-deps:
#     pip install --no-deps -r requirements.txt
#
# Why --no-deps: MeloTTS' dependency chain pulls build-only / heavyweight
# packages that either have no ARM64 wheel (e.g. numba, llvmlite via librosa)
# or are never used on the TTS path. We install the exact leaf packages we
# need and stub the unavailable native ones in-process (see melotts_zh.py §1).
# On x86/AMD64 the same --no-deps approach is used for consistency and to
# avoid accidentally pulling CUDA-enabled or heavyweight wheels.
#
# Packages that are NOT in this file and are installed separately by
# setup_env.bat (they either need dependency resolution or a special index):
#     - melotts        -> patched sdist (PyPI sdist is broken; see NOTES.md Step 4)
#     - torch          -> PyTorch CPU wheel index (both ARM64 and x86/AMD64)
#     - qai_appbuilder, numpy, soundfile, requests, pyyaml -> installed WITH deps
#
# See README.md ("Environment Setup") and NOTES.md for the full procedure.
# ---------------------------------------------------------------------
